Date helpers

The library also has general date functions. A selection:

Function

Returns

DateGetISOWeek dDate

The ISO 8601 week number (weeks start on a Monday).

DateGetISOYear dDate

The year the ISO week belongs to.

DateGetISOWeekDate dDate

The date as ISO year-week-day, such as "2009-W53-7".

DateGetISODayOfWeek dDate

The day of the week, 1 for Monday to 7 for Sunday.

DateGetDaysInMonth dDate

The number of days in the month.

DateGetLastDayOfMonth dDate

The last day of the month.

DateGetFirstDayOfYear dDate

The first day of the year.

DateGetLastDayOfYear dDate

The last day of the year.

DateChangeMonth dDate iMonths bLastDay

The date a number of months later or earlier.

DateChangeYear dDate iYears bLastDay

The date a number of years later or earlier.

DateSetDate iYear iMonth iDay

A date made from a year, a month and a day.

IsLeapYear iYear

True for a leap year.

DateGetMonthName dDate

The month's name; DateGetMonthNameLong for the long name.

DateGetDayName dDate

The day's short name; DateGetDayNameLong for the long name.

DateFormat dDate sFormat

The date written as a format string says, such as "yyyy-MM-dd".

IsValidDateString sDate

True when a string is a valid date.

ISO_LongToISO_Short sISO_Long

The two-letter country code for a three-letter one.

WindowsLocaleISO_Short

The two-letter country code of the computer.

All are called the same way:

Integer iWeek

Get DateGetISOWeek of ghoCalendarHolidays dDate to iWeek

Month and day names in a country's language

DateGetMonthName and DateGetDayName answer in the computer's language. These answer in the language of a country's holiday package - Swedish for "SE", Norwegian for "NO" - on any computer, and in the computer's language for a country without a package:

Function

Returns

MonthNameOfCountry iMonth bLongName bCapsFirstLetter sISO_Short

The month's name (1-12): long ("januari") or short ("jan").

DayNameOfCountry iDay bLongName bCapsFirstLetter sISO_Short

The day's name, day 1 being Monday: long ("måndag") or short ("mån").

ShortestDayNameOfCountry iDay bCapsFirstLetter sISO_Short

The shortest day name, as a calendar's column heading writes it ("Mo", "må").

CountryLocaleName sISO_Short

The country package's language, such as "sv-SE".

bCapsFirstLetter True writes the first letter in upper case: "Januari".

String sMonth sDay

Get MonthNameOfCountry of ghoCalendarHolidays 1 True True "SE" to sMonth

Get DayNameOfCountry of ghoCalendarHolidays 1 False True "NO" to sDay

The demo's Year Overview view uses them for its month names and day headings. A new country package sets its language with psLocaleName - see Adding a country.
