Holiday names

HolidayName goes the other way: it takes a date and a country and returns the name of the holiday or special day on that date, in the country's language. It returns an empty string for an ordinary day.

Boolean bOfficial

String sName

Get HolidayName of ghoCalendarHolidays dDate "US" (&bOfficial) to sName

The third parameter is passed ByRef. It is set to True when the day is an official holiday - a day off by law - and False when it is a special day that is not a day off, such as Mother's Day or Christmas Eve in many countries.

Holiday names exist for the countries that have a country package: today US, GB, NL, NO, ES and SE. See Adding a country to add another.

HolidayDetails - everything about the day

HolidayDetails returns the whole day as one tHoliday struct:

tHoliday Holiday

Get HolidayDetails of ghoCalendarHolidays dDate "GB" to Holiday

  • sHolidayName - the name in the country's language; empty when nothing falls on the date.
  • bNationalHoliday - True for an official holiday, a day off by law.
  • sFunction - the library function that gives the day, such as EasterDay or "AshWednesday - 1 day"; empty for a day on a fixed date in the country's package, such as 8 March.
  • sISO_Short and dDate - the country and the date you asked about.
  • iRegions - in the UK only: the regions where the day is a bank holiday, as the CI_UKRegion... bits (8 is the whole UK). 0 for other countries.

When more about a day is needed later, it is added to the struct, and calls that already use HolidayDetails keep working.

IsDateAHoliday

IsDateAHoliday asks the same question with ByRef parameters, and returns True when the country's package names the date:

Boolean bFound bIsHoliday

String sName sFunction

Get IsDateAHoliday of ghoCalendarHolidays dDate "SE" (&bIsHoliday) (&sName) (&sFunction) to bFound

The country decides. IsDateAHoliday returns False when the country has no package, or when its package does not name the date - even when one of the library's functions falls on it: Thanksgiving is a US holiday, so for Sweden on Thanksgiving Day the answer is False.

The country code

Every holiday function can be given the country code. A function whose date does not depend on the country simply ignores it, so you can always pass it and every call can look the same.
