A month calendar for FlexTron programs

cHolidayMonthCalendar draws one month of a country's calendar in a DataFlex 26 FlexTron program, with every day marked from this library: official holidays, special days, the weekend and closure days. The month and day names come in the country's language. Twelve of them make the demo's Year Overview view.

It is built on the cFTMonthCalendar class of the RDCFlexTron library (https://github.com/NilsSve/Library-RDCFlexTron), version 0.9.40 or later.

An optional part of the library

None of the library's own packages Use cHolidayMonthCalendar, and the library does not install RDCFlexTron. A program that only wants holiday dates gets nothing more. To use the calendar:

  1. Add RDCFlexTron to your workspace, as you added this library - see Adding the library to a workspace.
  2. Use the package where the calendar is: Use cHolidayMonthCalendar.pkg
  3. Put the calendar in a FlexTron host, such as RDCFlexTron's cFTGridHost.

Object oJuly is a cHolidayMonthCalendar

    Set psISO_Short to "US"

    Set piYear to 2026

    Set piMonth to 7

End_Object

Send Refresh to draw it - in End_Construct_Object for the first time, and again when the country, the month or the library's settings have changed.

What a day is

Mark

The day

ftcal-off

an official holiday on a weekday - a day off

ftcal-off ftcal-wkd

an official holiday on a weekend day

ftcal-spc

a named day that is worked, such as Mother's Day

ftcal-spc ftcal-wkd

a named day on a weekend day

ftcal-wkd

a day off every week (psWeekendMask)

ftcal-cls

a day the company is closed (padClosedDays)

The working days follow the library's settings - see Working days. RDCFlexTron draws the marks in its own colours, which follow the light or dark theme. Today is marked too. Point at a day to see its name.

What it counts

After Refresh the calendar tells what it found in the month:

Property

What it holds

piWorkingDays

the month's working days, also shown in the month's heading

piHolidays

the official holidays on weekdays

piSpecial

the named days that are worked

paNamedDays

the month's named days and closure days: date, name, marks and what each one is

Clicks and words

  • A click on a day marks it - in every calendar on the page - and reaches the calendar's OnDayClick event with the date. Set pbDayClick to False when only the page should answer the click, as the Year Overview view does.
  • The words of the tooltips are properties, English unless you set your own: psTextHoliday, psTextSpecial, psTextWeekend, psTextClosed and more, and psTextWorkingDaysNote ("%1 working days") for the heading.
  • In the Studio's Designer the calendar shows a month's shape.
