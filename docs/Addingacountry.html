Adding a country

Holiday names come from a country package: one object per country, based on the cNationalHolidays class. The library has packages for the US, GB, NL, NO, ES and SE; they are listed in CountryPackages.pkg.

To add a country:

  1. Copy a country package that is close to yours, such as NorwegianHolidays.pkg, and give the copy your country's name.
  2. Set psISO_Short to your country's two-letter code. Set psLocaleName to the Windows name of its language, such as "de-DE": the month and day names in that language come from it.
  3. Change the HolidayName function: for each holiday or special day in your country, call the library's date function, compare the date, and return the name in your language. Set bOfficialHoliday to True for the days that are off by law.
  4. Add a Use line for your package to CountryPackages.pkg.

Object oNorwegianHolidays is a cNationalHolidays

    Move Self to ghoNationalHolidayObject

    Set psISO_Short to "NO"


    Function HolidayName Date dInDate Boolean ByRef bOfficialHoliday Returns String

        ...

    End_Function

End_Object

Working days

The working-day functions ask the country package which days are official days off. By default these are the days HolidayName marks as official. When a country's days off differ by region, as in the UK, the package can override the IsOfficialDayOff function; see BrittishHolidays.pkg for an example.
