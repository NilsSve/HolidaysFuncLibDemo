  1. Using the demo program

Date Functions Test

View > Date Functions Test tries out every holiday date function of the library. The view works in three steps, top to bottom, and there is no button to press: the answer changes as soon as you change the function, the year or the country.

1. Pick a function

The list shows the holiday functions, such as EasterDay, Thanksgiving or ChristmasDayBH, and what each one asks for: a year, or a year and a country.

  • Type in the search field above the list to find a function by part of its name or description, such as midsummer or bank holiday. The footer shows how many functions match.
  • Rest the mouse on a row to read the function's description in a tooltip.
  • Click a column header to sort the list by that column. Then type in the list: a search box opens for that column, and Enter goes to the first match.

2. Year and country

The function you picked is shown with its description. Enter the Year (1753 to 2500) and the Country as a two-letter ISO code, such as US, GB or SE. Next to the code the view tells you whether the library has a holiday package for that country - without one, the function still gives the date, but there is no holiday name.

Some holidays need the country because they fall on different dates in different countries; Thanksgiving, for example, is a Thursday in November in the US and a Monday in October in Canada.

3. The answer

  • The date the function returns, written out in full, or a note when the function has no date for that year and country.
  • The holiday's name in that country's language package, and whether it is an official holiday.
  • The ISO week number, the number of days in the month, and the date in your computer's date format.
  • The call: the line of DataFlex code that gives this answer, ready to copy into your own program.
  • The same function for the two years before and after, so you can see how the date moves. Each year is a link: click a year to go to it, and the whole answer follows.

Dates are shown the way your computer's settings write them.

Is this date a holiday?

The last part goes the other way: enter a Date and a Country, and IsDateAHoliday tells you the holiday on that date and the function that finds it. The date starts at today, and the answer is shown at once.

Both country fields start with your computer's country. When you change one of them and the other is empty, the other takes the same country.
