  1. Using the demo program

Nations Data

View > Nations Data shows facts about every nation in the world, one at a time:

  • the ISO country codes (two-letter, three-letter and numeric) and the UN code;
  • the country's short and long names, capital city and continent;
  • the international calling code and internet domain;
  • the currency code, number and name;
  • the area and the population.

When the program starts, the view shows your computer's country.

Finding a nation

Use the usual DataFlex keys to find a nation, such as F7 and F8 for the previous and next record, or type a code in ISO Code Short and press Tab. The ... buttons, or F4, open a lookup list: click a column header to sort the list by that column, then type - a search box opens, and Enter goes to the first match ("SE" and Enter go to Sweden). The ISO - Country Codes link opens the official list of country codes at iso.org.

The flag

The nation's flag is shown to the right. Select File Type chooses the pictures:

  • .svg - sharp drawings from the open flag-icons set, found by the ISO code. When a country has none, the PNG picture is shown instead.
  • .png and .gif - the pictures named in the Flag field.

Exchange Rate

The Exchange Rate box converts an amount of the nation's currency to another currency, and the same amount back, at today's rates from ExchangeRate-API's free open access. Enter the Amount, and pick the other currency from the list - or type its three-letter code, such as EUR, USD or GBP. Below the two results are both rates and the day they are from.

The rates are fetched once each time the program starts, so the computer needs an internet connection; without one the box says that the service did not answer. The Rates By Exchange Rate API link is the credit the service asks for.

Saving

Save a change with Ctrl+S or the Save button. A nation is never saved without its continent: if the Continent Name is empty, the view says so and does not save.

The Nations table is also where the other views find a country's name. This view does not use the holiday library.
